# 《错位大侦探》UI 视觉重设计方案
## Codex 稳定执行版

> 适用范围：Admin 之外的玩家端 UI，重点覆盖 **Web / WeChat 微信小游戏**。
>
> 目标：在不修改现有核心玩法、不破坏已上线功能和数据结构的前提下，替换当前偏绿色、大色块、工具化的视觉风格，建立一套适合《错位大侦探》长期内容体系的统一 UI。
>
> 核心方向：
>
> **现代侦探档案馆 + 轻博物馆 + 内容图片主导**
>
> 本文档主要解决视觉和页面结构，不重复设计业务逻辑。内容世界、章节、星级、EXP、收藏等业务规则以《错位大侦探_内容体系与成长系统_Codex稳定执行版.md》为准。

---

# 1. 改造原则

本次是 UI / UX 重设计，不是重新开发游戏。

Codex 必须遵守：

1. 保留现有找穿帮玩法。
2. 保留现有拼图 / 错位还原玩法。
3. 保留现有登录、用户、关卡、音效、提示等功能。
4. 不修改资源 URL 和已有 Level ID。
5. 不因为 UI 重设计而重写业务层。
6. Web 和 WeChat 尽量保持相同视觉规范。
7. 优先复用现有组件，仅调整布局和样式。
8. 禁止顺手升级无关依赖。
9. 禁止大规模格式化项目。
10. 每完成一个主要页面必须进行构建和回归测试。

---

# 2. 视觉定位

不要继续使用：

```text
绿色大背景
绿色大按钮
高饱和渐变
大量彩色功能块
传统工具型小程序视觉
```

新的视觉定位：

> **现代侦探档案馆 / Detective Archive**

关键词：

```text
Detective Archive
Editorial
Museum
Warm Paper
Dark Navy
Muted Gold
Large Photography
Minimal UI
Premium Casual Game
Content First
```

整体体验应该更接近：

```text
一本正在被玩家逐渐填满的案件档案
+
一个收藏不同世界奇案的视觉博物馆
```

而不是：

```text
绿色休闲小游戏大厅
```

# 10. 圆角规范

统一：

```text
大型内容卡：20px
普通卡片：16px
按钮：14px
小标签：8px
图片：16px
弹窗：24px
```

禁止不同页面随意出现：

```text
6 / 8 / 12 / 17 / 22 / 30px
```

等大量不统一圆角。

---

# 11. 间距系统

基础单位：

```text
4px
```

推荐：

```text
XS  = 4
S   = 8
M   = 12
L   = 16
XL  = 24
XXL = 32
```

页面左右安全边距：

```text
16px
```

宽屏 Web 最大内容宽度：

```text
480~560px
```

如果当前 Web 是手机竖屏模拟：

继续保持竖屏游戏体验。

---

# 12. 阴影

减少明显阴影。

卡片建议：

```text
非常轻的阴影
+
1px 柔和边界
```

示意：

```css
box-shadow: 0 4px 18px rgba(24, 35, 49, 0.06);
border: 1px solid rgba(24, 35, 49, 0.06);
```

不要：

```text
强黑阴影
霓虹 Glow
绿色 Glow
```

---

# 13. 图片原则

《错位大侦探》的视觉核心是：

> 游戏内容图片。

UI 必须给图片让位。

原则：

1. 大图优先。
2. 少用纯色占据屏幕。
3. 世界卡片使用内容场景图。
4. Chapter 使用代表性封面。
5. 图片上文字必须增加 Overlay 保证可读性。
6. 不要为了 UI 装饰遮挡大量图片。

---

# 14. 图片 Overlay

世界 / Chapter 大图卡建议：

```css
linear-gradient(
  to top,
  rgba(18, 27, 38, 0.78),
  rgba(18, 27, 38, 0.08)
)
```

实际实现可以根据平台调整。

重点：

```text
底部文字区域深
顶部图片保持清晰
```

# 15. 首页重新设计

首页信息层级：

```text

2. 继续案件
3. 内容世界

5. Bottom Navigation
```

不要在首页堆太多运营入口。

# 16. 首页顶部

顶部不要传统绿色 Header。

推荐：

```text
┌─────────────────────────┐
│ 错位大侦探              │
│                         │
│ Lv.12  敏锐侦探    86★ │
│ ███████░░   460 / 520  │
└─────────────────────────┘
```

视觉：

```text
深蓝灰背景
暖金等级 / 星星
白色主文字
低对比度辅助文字
```

可以增加极淡纹理：

```text
指纹
放大镜
案件线
档案编号
坐标
```

Opacity：

```text
3%~8%
```

禁止做成警察局、犯罪现场的沉重风格。

不要占屏过多。

建议：

```text

```

根据当前屏幕实际适配。

顶部的作用是：

```text
身份 + 成长反馈
```

不是 Banner 广告位。


```text

+
少量 Theme Color
```

建议：

```text

│                         │
│ 第一卷                   │
│ 洛神赋                   │
```


不要完全隐藏未解锁 Chapter。

玩家需要看到未来目标。

# 30. 找穿帮页面

主要元素：

```text
关卡图
已找到数量
提示按钮
必要的时间 / 错误状态
```

不要同时出现大量文字说明。

首次进入玩法可以使用一次性引导。

---

# 31. 拼图页面

视觉系统与找穿帮一致。

只替换中间玩法区域。

保持：

```text
同一顶部栏
同一背景
同一按钮体系
同一结算页
```

让用户感知：

```text
这是同一个案件体系中的另一种调查方式
```

而不是进入另一个小游戏。

---

# 32. 提示按钮

提示属于辅助操作。

不要使用最大主 CTA 样式。

推荐：

```text

放大镜 / 灯泡 icon
提示
```

如果有剩余次数：

```text
提示 ×2
```

# 34. Secondary Button


# 46. 动画

动画原则：

```text
轻
短
有反馈
```

建议：

```text
页面进入：180~240ms
按钮：100~160ms
卡片：180~220ms
星星结算：逐颗出现
```

禁止为了重设计增加大量复杂动画。

# 65. 最终视觉方向

统一总结：

```text
旧：
绿色背景
+
彩色功能块
+
传统休闲小游戏 UI

↓

新：
暖米白页面
+
深蓝灰结构
+
暖金成长反馈
+
大尺寸内容图片
+
侦探档案馆
+
轻博物馆收藏感
```

最终设计原则：

> **让“案件内容”成为视觉主角，让 UI 负责组织内容，而不是让 UI 的颜色压过内容。**

《错位大侦探》的长期内容会同时包含现代生活、中华文化、环球旅行、幻想和脑洞题材，因此全局 UI 必须足够中性、高级、稳定；不同内容世界的个性应主要通过 **封面图片 + 少量主题色** 表达，而不是每进入一个系列就彻底更换整套 UI。
