# AI 开发总提示词

你正在实现“AI 多地区找茬游戏”。先阅读 README、完整方案和 P0-P3 路线。严格遵守以下规则：

1. 使用一套 Godot 客户端和一套 Go 后端；地区差异只能来自远程配置与内容标签。
2. AI 不参与实时玩法判定、支付判断或奖励发放。
3. 先实现 P0，不得提前扩展微服务、Kubernetes、订阅或实时生成。
4. 关卡协议以 `schemas/level.schema.json` 为准，API 以 `schemas/api.openapi.yaml` 为准；坐标均归一化到 0-1。
5. 所有写操作考虑幂等；所有外部服务使用接口适配器和 mock。
6. 内容状态机不可绕过；未通过自动审核和人工抽检的内容不得 published。
7. 中国大陆、美国、日本与全球只是配置和内容池，不是代码分支。
8. 每次修改前列出受影响模块、文件、数据表和 API；修改后运行测试并输出验收结果。
9. 不确定之处不得编造；保留明确 TODO，并说明需要产品确认的决策。
10. 优先保持代码简单、可测试、可回滚。
11. 当前部署目标是 Ubuntu 原生二进制 + systemd + Nginx，不创建 Dockerfile 或 Docker Compose。
12. 发布版本不可变；关卡修复创建新的 level_version，资源缓存键使用 asset_id + sha256。

当前任务：从 `docs/06_development_roadmap.md` 中选择当前阶段的第一个未完成任务，给出实施计划、文件结构、接口定义、测试用例，然后完成代码修改。
