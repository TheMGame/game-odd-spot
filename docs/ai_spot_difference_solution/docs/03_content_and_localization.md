# 3. 内容、多地区与中国大陆

## 3.1 地区模型

必须区分：`market_region`（商业与合规市场）、`locale`（界面语言）、`content_preference`（实际内容偏好）。初始地区由商店国家、系统语言、系统地区和 IP 综合判断，用户可手动切换内容偏好；后续推荐以行为为主。

## 3.2 标签体系

标签至少包含 regions、themes、styles、scenes、season、audience、difficulty、risk、generation_model、prompt_version。风险标签覆盖政治、地图边界、宗教、真实人物、明星、商标、版权角色、暴力、儿童不宜和文化敏感。

## 3.3 中国大陆内容策略

优先主题：中国传统节日、春节、元宵、端午、中秋、国风插画、古代生活、园林、熊猫、家庭生活、美食街、校园、城市通勤、乡村与治愈场景。

需要谨慎：地图与边界表达、政治人物和符号、宗教场所与人物、真实历史争议、明星肖像、知名品牌、现有动画或游戏角色、未成年人敏感内容。

中国大陆不只是语言本地化，还涉及渠道差异：iOS 可使用 Apple IAP；Android 可能需要国内渠道包、渠道支付、国内广告聚合、隐私 SDK 清单和合规弹窗。架构上通过适配器实现，不允许复制整套客户端代码。

## 3.4 其他首发市场

- 美国：万圣节、圣诞节、公路旅行、露营、国家公园、温馨住宅、小镇和家庭。
- 日本：樱花、猫、可爱插画、咖啡店、夏日祭、温泉和四季。
- 全球英语：动物、美食、梦幻、太空、四季、海滩、城市和童话。

每个市场保留约 20% 全球内容，用于探索跨地区兴趣。

## 3.5 AI 关卡生产

推荐流程：选题 → Prompt 模板 → 生成基础图 → 选择可编辑对象 → 局部编辑生成目标图 → 保存 mask → 图像差分验证 → 内容安全与版权检测 → 难度评分 → 人工抽检 → staging → 1% 灰度 → 扩量或下架。

禁止分别生成两张相似图片，因为会产生大量不可控差异。应基于同一张基础图做局部编辑。

## 3.6 自动质量检查

- 尺寸一致、哈希与资源完整性。
- 预期 mask 和实际图像差分的 IoU 达标。
- 非目标区域变化低于阈值。
- 差异数量准确，区域不重叠、不贴边、不过小。
- 不在人物面部、手指等高风险畸形区域制造差异。
- 无乱码文本、异常肢体、品牌 Logo、版权角色和敏感内容。
- 难度分布合理，同一关包含易、中、难差异。

## 3.7 内容反馈闭环

记录每个差异首次发现耗时、提示率、误点率和最终未发现率。若某差异提示率过高或误点集中，自动标记复审。关卡质量分由静态质检和真实数据共同构成。
