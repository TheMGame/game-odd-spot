# 热点筛选与编辑规则

## 可优先选择

- 科学、航天、天文和自然现象
- 体育赛事和大众健身话题
- 科技产品类别或通用技术趋势（避免品牌中心化）
- 公共文化活动、展览、节气、节庆和非遗
- 动植物、环保和城市公共生活
- 无害且能形成丰富场景的网络生活趋势

## 必须排除

- 竞选、政治宣传、领土争议或可能引发对立的政治事件
- 战争、恐袭、死亡、灾难、犯罪、失踪和医疗悲剧
- 对真实人物的指控、嘲讽、隐私曝光或未经证实的传闻
- 涉及未成年人的敏感事件
- 必须复制名人脸、新闻照片、影视角色、球队徽标或商业商标才能成立的主题
- 主要依靠可读文字、口号、Logo 或 UI 截图才能识别的主题
- 可能把现实受害者或严肃公共事件娱乐化的选题

## 候选评分

每项按 0–2 分评估，优先选择总分最高且无排除项的候选：

1. **时效性**：是否发生或持续于最近 24–48 小时。
2. **可信度**：是否有官方/一手来源和独立可靠来源核实。
3. **视觉性**：能否自然形成细节丰富的单幅场景。
4. **玩法性**：能否放入 8 个小而唯一、不会歧义的异常物品。
5. **安全性**：是否适合轻松游戏化且不消费真实伤害。
6. **耐久性**：即使玩家晚几天看到，主题是否仍可理解。

```markdown
- 选择理由：
- 事件日期：

## 来源

- [来源标题](URL) — 发布日期：YYYY-MM-DD；支持信息：

## 其他候选

```

引用只用于选题核实。正式画面不得复制来源图片的构图或受版权保护的表达。
